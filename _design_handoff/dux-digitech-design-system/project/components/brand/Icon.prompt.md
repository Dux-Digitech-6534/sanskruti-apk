Thin-stroke line icon ported from the production DUX chat surface — use for all inline UI iconography.

```jsx
<Icon name="sparkle" size={18} />
<Icon name="send" size={16} color="var(--text-on-brand)" />
```

21 glyphs: filter, clock, truck, building, rupee, calendar, box, search, sparkle, send, plus, moon, sun, chevron, layers, refresh, check, close, copy, download, user. All 24×24, 1.7 stroke, round caps. Color follows `currentColor` unless `color` is set. `ICON_NAMES` exports the full list.
