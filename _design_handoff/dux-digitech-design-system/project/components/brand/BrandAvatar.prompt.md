The DUX assistant identity chip — DX monogram in a rounded square with a faint brand-gradient ring. Use as the assistant avatar in chat turns and the header brand mark.

```jsx
<BrandAvatar size={34} />
```

Point `markLight` / `markWhite` at the DX mark PNGs (`assets/dux-mark.png` / `dux-mark-white.png`). The white mark shows automatically in dark theme. Set `ring={false}` for a flat version.
